# Zhiqing Wang — personal website

A static academic portfolio prepared for rebeccawzq.github.io. No build step or client-side JavaScript.

Run `python3 -m http.server 8000` in this folder to preview.

Research narrative: scaffolding progress → intervening in conversation → coordinating attention across agents. The narrative is editorial framing grounded in the projects, not a claim that all papers studied proactive intervention.

Image provenance is documented in ASSET-SOURCES.md. Local sources/ contains downloaded public manuscripts for figure extraction and is excluded from Git. The deployment workflow uploads only HTML, CSS, .nojekyll, and assets.

Publishing: push to rebeccawzq/rebeccawzq.github.io on main and select GitHub Actions under Settings → Pages. The currently connected GitHub account is different; publishing requires access to the intended repository. No deployment has occurred.
